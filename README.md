# HHA Investigation Report Portal

A professional, password-protected static website for executive leadership to review HR investigation findings.

## Access

**URL:** Deploy to Netlify from this repository
**Password:** Contact IT Administrator for access credentials

## Features

- Password-protected access
- Mobile-responsive design
- Interactive charts and visualizations
- Document viewer for evidence files
- Print-ready executive summary
- Actionable recommendations checklist

## Pages

1. **Dashboard** - Executive overview with key metrics
2. **Timeline** - 90-day activity visualization
3. **Incidents** - Detailed breakdown of critical events
4. **Evidence** - View and download investigation files
5. **Actions** - IT response documentation
6. **Summary** - Print-ready formal report
7. **Recommendations** - Next steps for leadership

## Technology

- HTML5, CSS3, JavaScript
- Bootstrap 5.3 (CDN)
- Chart.js 4.x (CDN)
- Font Awesome 6 (CDN)
- Papa Parse (CSV parsing)

## Security

- Session-based authentication
- No sensitive data stored in browser
- All files served over HTTPS (when deployed)
- No external tracking or analytics

## Deployment

Deploy this repository to Netlify or any static hosting provider.
